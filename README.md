# Лабораторна робота №5. Варіант 17

**Тема:** використання SFML у C++ проєкті, пакетний менеджер vcpkg, система збирання CMake.
**Завдання (варіант 17):** рух тіла похилою площиною з тертям.

Програма моделює ковзання тіла похилою площиною з урахуванням сили тяжіння та тертя ковзання. Користувач змінює кут нахилу площини та коефіцієнт тертя, запускає, призупиняє й перезапускає моделювання. Параметри руху відображаються у вікні в реальному часі.

![Загальний вигляд програми](screenshots/main.png)

## Фізична модель

Тіло розглядається як матеріальна точка масою `m` на нерухомій похилій площині з кутом нахилу `α`. На тіло діють:

- сила тяжіння `m·g`;
- нормальна реакція опори `N = m·g·cos α`;
- сила тертя ковзання `F_тр = μ·N = μ·m·g·cos α`.

Складова сили тяжіння вздовж площини: `F = m·g·sin α`.

**Умова початку руху:** `tg α > μ`. Критичний кут: `α_кр = arctg(μ)`. Якщо `tg α ≤ μ`, тіло залишається в спокої.

## Математична модель

Другий закон Ньютона вздовж площини:

```
a = g · (sin α − μ · cos α),   якщо tg α > μ
a = 0, v = 0,                  якщо тіло стоїть
```

Аналітичний розв'язок для руху зі стану спокою:

```
v(t) = a · t
s(t) = a · t² / 2
t_кін = sqrt(2 · S / a)
```

Чисельне моделювання з кроком `dt` (напівнеявний метод Ейлера):

```
v(n+1) = v(n) + a · dt
s(n+1) = s(n) + v(n+1) · dt
```

Крок `dt` береться з `sf::Clock` і обмежується значенням 0.02 с.

## Збирання та запуск

**Потрібно:** Visual Studio з компонентом «Desktop development with C++» та CMake, встановлений vcpkg, змінна середовища `VCPKG_ROOT`, що вказує на каталог vcpkg.

1. Склонувати репозиторій. Шлях до проєкту краще використовувати без кирилиці.
2. У Visual Studio вибрати **File → Open → Folder...** і відкрити каталог проєкту.
3. Вибрати конфігурацію **default**. Під час першої конфігурації vcpkg збере SFML (10–20 хвилин).
4. Вибрати ціль запуску **SFML_Lab.exe**.
5. **Build → Build All**, потім запустити програму.

Шрифт береться з `resources/fonts/arial.ttf` або з `C:/Windows/Fonts/arial.ttf`.
